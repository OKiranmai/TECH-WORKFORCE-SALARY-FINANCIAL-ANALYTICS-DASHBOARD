# Tech Workforce & Financial Analytics Dashboard 📊

A Power BI project analyzing the global tech workforce — covering salaries, career growth, job satisfaction, skills/certifications, and personal expenses & savings.

## Overview

Built on the **Tech Salary Dataset** (CSV), this project includes 6 interactive dashboards:

- **Executive Dashboard** — high-level workforce KPIs and summary
- **Salary Analytics** — compensation by experience, education, and role
- **Career Growth Analytics** — promotions and career progression trends
- **Employee Job Satisfaction Analytics** — satisfaction, retention risk, and work arrangements
- **Expenses & Savings Analytics** — personal finance breakdown by location and salary
- **Skills & Certifications Analytics** — top-paying skills and certifications
